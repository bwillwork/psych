# Psych

## **Note:** This is still a work in progress

This is a fun project for those interested in personality tests.  It combines six popular personality tests for general personality and romance.
1. Big 5 Personality Test
2. Myers Brigs Personality Test
3. The PEN Personality Test
4. 5 Modern Relationships Test
5. Seduction Archetypes Test
6. 6 Styles of Loving Test

It works like this.  The home page will allow you to choose which tests you wish to take, then you will be given a test that is made up of all the questions of each test in a random order.  Once finished, you will be sent to results page which will show you the results.


This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.11.

## Development server

To start a local development server, run:

```bash
ng serve
```
